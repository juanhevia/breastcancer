# Pesos y resultados

Cada entrenamiento crea una subcarpeta con pesos, configuración, métricas y curvas. Los artefactos originales se excluyen de Git; este README conserva la carpeta.

Los historiales, métricas agregadas y gráficas exportados para consultar desde
GitHub están en [docs/resultados](../docs/resultados/README.md). Es una instantánea
documentada; los entrenamientos nuevos no se suben automáticamente. Los pesos y
las predicciones individuales permanecen en `models/`.
